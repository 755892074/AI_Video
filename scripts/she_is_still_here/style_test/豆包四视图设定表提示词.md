# 《她还在》角色四视图设定表 · 豆包提示词

> 用途：每个角色 1 张合成设定表（正面/背面/侧面/全身 + 表情），**人审定稿 + 归档**。
> H3 渲染喂图不用这张（合成图脸分辨率低且模型会懵），H3 仍用正脸半身高清单图当 Picture 主锚。
> 关键：豆包 SeedDream 可传**参考图**（把现有 bean 定妆图传上去锁脸），比纯文字稳得多。

## 江彻（刑警 · 疲惫版）

**参考图**：`characters/she_is_still_here/jiangche/bean_jiangche.png`（贴图锁脸，但要在 prompt 里压"疲惫老化"——豆包原图偏年轻帅）

```
角色设定表，同一个中国男人画 4 次，2x2 网格排列，每格都是同一人：

四格人物完全一致：中国男性约 31 岁，黑色短寸头，浅胡茬，眼窝深、黑眼圈明显（疲惫刑警），
下颌线条硬朗，法令纹隐约，表情克制疲惫不笑。
服装：深炭灰色拉链夹克 + 素灰衬衫 + 深色长裤（便衣刑警，不穿制服）。
写实 CG 电影质感（UE5/Octane 渲染感），冷调低饱和调色，纯灰 studio 背景，柔光均匀，
四格同一个人，角色设计表标准排版。
非卡通非动漫。图上不要有任何文字/字母/水印/标注。
```

## 出图后命名规范（沿用角色库约定）

```
characters/she_is_still_here/<角色>/turnaround.png      ← 设定表（人审归档）
characters/she_is_still_here/<角色>/reference.png       ← H3 主锚正脸图（已有 bean_ 图可改名）
```

> ⚠️ 四视图一致性（尤其同脸）是出图难点，若豆包一次出崩（脸不一致/角度乱），
> 可改用"逐角度单出 + 贴参考图锁脸"，最后用拼图工具合成一张，效果通常更稳。
