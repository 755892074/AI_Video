# 声音驱动 H3 工作流 v1（已验证 · 2026-08-30）

> 核心结论：**角色对白用声音驱动，情绪/表情/口型全部对得上**。真人录音 → H3 ref_audios 直播模式 → 成片自带音轨。
> 验证：蜘蛛怪三镜（小乐求救 / 嘉玲怒吼 / 阿妈特拉斯）全部成功。

## 一、完整流程

```
1. 剧本台词 → 手机录音（带情绪，每句单独录）
   - 情绪要点：求救=虚弱断断续续带喘息；怒吼=爆发吼出来；咒语=用力喊出咏唱感
   - 命名：scene_xxx_role.mp3，每句 2~15 秒
2. m4a → mp3（48kHz，ffmpeg 转换）
   存到 D:\WorkBuddy\AI_Video\shots\audio\
3. manifest 每个 shot 加 audio 字段：
   "audio": "audio/scene_spider_xiaole.mp3"
4. batch_r2v_chain.py 自动：上传音频 → LoadAudio(142) → H3 ref_audios.ref_audio_0
5. H3 生成：带原生音轨（aac 32k stereo）+ 口型同步 + 情绪表情匹配
```

## 二、关键：H3 音频参考的两种行为模式（Prompt 控制）

| 模式 | 触发词 | 效果 |
|---|---|---|
| **直播模式（推荐）** | prompt 里写 `her/his voice and emotion exactly matching the reference audio` + `lip-synced to the reference audio voice` | **直接播原录音**，口型/表情/情绪全同步，声线=原声 |
| 克隆重念模式 | 只写台词不说匹配参考音频 | H3 用参考音频学声线重念台词，情绪/停顿被简化 |

**固定用直播模式措辞。** 两句必备触发词：
```
...her voice and emotion exactly matching the reference audio, saying in Chinese: "台词"
...Her mouth moves in sync with each syllable, lip-synced to the reference audio voice.
```

## 三、Prompt 固定配方（六段式）

- **Subject 1**: 嘉玲（Picture 1，fully_preserved，`do not alter or reshape the face`）
- **Subject 2**: 小乐（Picture 2，同上）
- **Subject 3**: 场景（Picture 3，partially_preserved）
- **Subject 4+**: 纯文字怪物（无 picture，放最后）
- **Retention**: 两角色人脸全部 `fully_preserved - do not alter or reshape the face`
- **台词**：写进 Summary + Detailed Description 两处，中文台词用省略号标停顿
- **语言锁**：`All dialogue in Chinese, no other language, no narration.`
