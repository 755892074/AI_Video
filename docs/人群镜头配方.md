# H3 人群镜头标准配方（Crowd Shot Recipe）

> 来源：2026-08-25 群演专项测试（8 镜 480p 远景人群）+ 缓解验证批次（6 镜 720p 中近景人群）的实测结论。
> 状态：**用户验收通过**（"好了很多"），可作后续拍摄人群镜头的默认模板。

## 背景：H3 的三大人群短板

实测发现（与社区评测一致，属 H3 模型级限制）：

1. **人多了动作静止且雷同**——H3 对多人独立运动建模弱，倾向把人群当静态背景纹理处理
2. **移动的人脸糊/崩**——广角/远景人脸细节严重模糊 + 运动模糊；低分辨率会放大
3. **走路漂移（滑步）**——步态/重心/脚地接触等精细物理是 AI 视频模型通病

## 标准配方（默认套用）

```
分辨率     megapixels = 0.7（720p 级）    # 治脸糊，16GB 卡可跑
景别       中景 / 近景为主                # 不拍远景人头海
人数       8-20 人                        # 模型"带得动"的上限
前景       2-4 人差异化动作               # 一人停/一人打电话/一人转头
背景       人群静止或慢速缓行             # 避免集体运动
动作速度   leisurely stroll 级            # 弱化漂移感
镜头      一个镜头只有一个主动作          # 不叠多动作
```

## Prompt 模板

### 人群质量通用约束段（CROWD_QUALITY）

```
Crowd: mixed ages, heights, outfits and skin tones. Each visible person
has a distinct pose and direction of movement — some stand, some walk
slowly, one checks phone, one turns head, one chats. People naturally
overlap and stand at varying depths. NO repeated faces, NO synchronized
mechanical movement, NO deformed hands, NO empty blank expressions.
```

### 前景差异化示例（以咖啡馆为例）

```
Foreground: a man sips coffee at a window table, a woman reads a
newspaper, a teenager scrolls a phone. Background: ten pedestrians
stroll leisurely along the sidewalk, unhurried.
```

### 背景处理两种手法

- **静止化**：`people stand nearly still, like a frozen afternoon`
- **散景化**：`background crowd softly blurred, out-of-focus bokeh`

## 反模式（避免）

| 反模式 | 后果 |
|---|---|
| 远景 + 数百人 | 必然静止雷同，远景小人脸全糊 |
| 快速走/跑的大群人 | 滑步明显，肢体崩 |
| 多人同时独立动作 | 模型顾不过来，动作塌缩 |
| 0.4MP 拍带近景脸的镜头 | 近景人脸都糊 |
| 一镜多主动作 | 没有一个动作做得好 |

## 边界（配方救不了的）

- 大场面（演唱会全景、春运候车厅全景、万人大场景）→ 换模型（Seedance 2.5 / Veo 3.1）或只做虚化散景背景
- 多人复杂走位戏 → H3 单镜内做不出，拆镜或换模型
