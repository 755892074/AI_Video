# Ollama 模型对比测试报告（2026-08-11）

## 一、耗时对比（同题《蚀骨》暗黑复仇短剧，900 token 上限）

| 模型 | 模式 | 耗时 | 速度 | 说明 |
|---|---|---|---|---|
| qwenab 9B (Q6_K) | CPU (num_gpu=0) | 228.1s | 3.9 tok/s | 纯 CPU 推理 |
| qwenab 9B (Q6_K) | GPU (num_gpu=999) | 31.6s | 28.5 tok/s | 全量上卡（7.4GB < 剩余 9.2GB 显存） |
| mythomax 13B (Q6_K) | CPU (num_gpu=0) | 52.9s | 0.0（仅 1 token）⚠️ | 退化，不可用 |
| mythomax 13B (Q6_K) | GPU (num_gpu=999) | 90.8s | 9.9 tok/s | 混合模式（13B≈10GB 塞不进剩余显存，部分走 CPU） |

**结论：**
- qwenab：**GPU 比 CPU 快约 7.2 倍**（228.1s → 31.6s）。
- mythomax 纯 CPU 段退化（同提示词 GPU 段正常出 900 token，故非提示词问题，是该 13B 模型强制纯 CPU 在本环境异常）。
- mythomax GPU 段为混合模式（13B 无法全量塞入被 ComfyUI 占用的剩余显存），故 90.8s 慢于 qwenab 纯 GPU。

## 二、创造力评测（暗黑/强情绪题材，禁色情）

| 维度 | qwenab | mythomax |
|---|---|---|
| 敢写/尺度 | ✅ 氛围狠、描写有血肉 | 偏通用动作戏，张力不足 |
| 中文对白自然度 | ✅ 有腔调、有潜台词 | 偏说明式、扁平 |
| 结构服从力 | ✅ 严格嵌套「镜号/画面/对白/承接」，易解析进 manifest | ⚠️ 每镜被拍平为 1.镜号 2.画面 3.对白 4.承接 列表，难解析 |
| 剧情连贯性 | ✅ 人物动机清晰、有因果 | 偏薄 |

## 三、结论与建议
- **剧本引擎默认用 qwenab**：质量高、CPU/GPU 均稳定、输出格式对流水线最友好。
- 若日后要更「写作向」，可试 **qwenwriter（14.8B，本次未测）**。
- **mythomax 不建议做剧本主引擎**：创意弱 + 纯 CPU 退化不可用 + GPU 混合模式慢。
- 流水线接入铁律：单发顺序请求（绝不并发）、跑前探活、维护 messages 历史实现多轮记忆、num_gpu 按显存余量决定（视频任务占显存时走 CPU）。

## 四、异常记录
- mythomax 纯 CPU 仅出 1 token：疑似该 13B 模型强制 num_gpu=0 在本环境退化，非提示词问题（同提示词 GPU 出 900 token）。需重开 ollama 后单独复测。
- 用户在测试完成后关闭了台式机 ollama 客户端：已捕获的结果不受影响；后续补测/接流水线需重新启动 ollama。
